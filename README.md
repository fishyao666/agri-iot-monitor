# 栖地 · 咖啡园环境监测原型

## 启动后端

需要 Python 3.9 或更高版本，不需要安装第三方包。

```powershell
python server.py
```

打开 <http://127.0.0.1:8000>。后端首次计算模型结果需要几秒；前端会自动请求 `/api/analysis`。也可访问 `/api/health` 检查服务，或 `/api/evaluate` 查看完整 JSON 结果。

## 后端做了什么

- 生成 7 天、每 15 分钟一条的咖啡园多传感器数据，并保留人工植入的异常标签用于评估。
- 对缺失读数线性插补，对孤立尖峰执行滚动 Hampel 筛查。
- 计算 IQR 基线、基础 Isolation Forest，以及加入 4 小时滚动均值、标准差、范围和斜率的 Isolation Forest。
- 通过 Precision、Recall、F1 比较检测效果；页面读数、图表和 CSV 导出由后端分析结果驱动。

此版本使用 Python 标准库实现 Isolation Forest，以便无需安装依赖即可运行。数据和标签是可复现的合成样本；评估分数只用于演示方法流程，不能代表真实农场效果。接入实际传感器后，应使用农艺师确认的异常标签重新评估和调整阈值。
